


#  Alzheimer’s Disease Detection using Brain MRI (Edge AI Deployment)

##  Overview
This project focuses on detecting **Alzheimer’s disease** from Brain MRI images using a deep learning model trained on **Edge Impulse** and deployed on an **ESP32-CAM** for real-time edge inference.

The MRI dataset was preprocessed and uploaded to Edge Impulse, where an image classification model was trained and optimized for embedded deployment. The optimized model was then exported and deployed to the ESP32-CAM microcontroller, enabling lightweight, low-power, on-device prediction without relying on cloud processing.

---

##  Key Highlights

-  Brain MRI image classification for Alzheimer’s detection  
-  Model training and optimization using Edge Impulse  
-  Deployment on ESP32-CAM for real-time inference  
-  Low-cost, edge AI–based healthcare prototype  
-  Designed for portable and offline medical screening support  

---
##  Tech Stack

- Edge Impulse (Model Training & Optimization)  
- ESP32-CAM (Embedded Deployment)  
- Embedded C / Arduino IDE  
- Deep Learning (Image Classification)

##  Project Significance

This project demonstrates the practical integration of **Deep Learning + Embedded Systems + Edge AI** for real-world healthcare applications, enabling affordable and portable early screening solutions.
